# 🚀 Современное портфолио на React + TypeScript (Vite)

Премиальный одностраничный шаблон персонального портфолио для разработчика с поддержкой темной/светлой темы, интерактивным модальным окном проектов, фильтрацией навыков и плавной навигацией.

## 🌟 Возможности шаблона

- **Навигация (Sticky Navbar)**:
  - Ссылки со скролл-шпионом (Scroll Spy), автоматически подсвечивающим текущий раздел на экране.
  - Переключатель темной и светлой темы с сохранением в `localStorage`.
  - Кнопка быстрого перехода к контактам.
  - Адаптивное меню-шторка (Drawer) для смартфонов.
- **Главный экран (Hero Section)**:
  - Статус доступности к работе («Открыта к интересным проектам»).
  - Заголовок с анимированным градиентным текстом.
  - Карточка аватара с неоновым свечением и плавающими технологическими бейджами.
  - Кнопки быстрого действия («Смотреть работы», «Связаться», «Резюме»).
  - Блок ключевых показателей и статистики.
- **Мои работы (Projects)**:
  - Фильтрация проектов по категориям (`Fullstack`, `Frontend`, `Все`).
  - Превью-карточки со ссылками на Live Demo и репозиторий GitHub.
  - Интерактивное модальное окно с детальным описанием архитектуры и фич.
- **Навыки и Языки (Skills & Languages)**:
  - Интерактивный каталог языков программирования с индикаторами уровня владения и опытом.
  - Стек фреймворков (React, Next.js, Redux Toolkit, Zustand и др.) и инструментов (Git, Vite, Docker, Figma).
  - Секция иностранных языков общения (Русский, English, Deutsch) с шкалой владения.
- **Обучение и Курсы (Courses & Certifications)**:
  - Список оконченных курсов (Яндекс Практикум, Hexlet, Stepik, Coursera и др.).
  - Изученные темы, ID сертификатов и ссылки на подтверждение квалификации.
  - Блок высшего академического образования.
- **Опыт работы (Experience)**:
  - Таймлайн карьеры с описанием ролей, результатов и используемых технологий.
- **Контакты и Форма связи (Contact)**:
  - Быстрое копирование почты и никнейма в Telegram в один клик.
  - Интерактивная форма обратной связи с валидацией и уведомлением об успешной отправке.
- **Футер (Footer)**:
  - Кнопка возврата наверх, копирайт и ссылки.

## 🛠 Как запустить проект локально

1. Установите зависимости (если еще не установлены):
   ```bash
   npm install
   ```

2. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

3. Откройте в браузере: `http://localhost:5173/`

4. Собрать production-билд:
   ```bash
   npm run build
   ```

## ✏️ Как настроить свои данные

Все персональные данные, тексты, ссылки, проекты, курсы и навыки вынесены в один файл:
👉 [`src/data/portfolioData.ts`](file:///c:/Users/Orbit-CS/Documents/portfolio/src/data/portfolioData.ts)

Просто откройте этот файл и замените текст на свой:
- `personal`: Имя, фамилия, должность, био, ссылки на резюме и аватар.
- `contacts`: Почта, Telegram, GitHub, LinkedIn, локация.
- `projects`: Ваши реальные проекты, скриншоты, ссылки и теги.
- `skillCategories`: Ваши навыки, технологии и прогресс.
- `languages`: Языки общения и уровень владения.
- `courses`: Оконченные курсы, сертификаты и платформы.
- `experience`: Места работы, стек и достижения.
